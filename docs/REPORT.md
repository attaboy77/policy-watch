# 타 산업 전용 세제 기사 제외 — 규칙 추가와 과거 데이터 검증 (2026-11-27)

## 요약

- **규칙**: 제목에 당사 업종과 무관한 산업명과 세제 단어가 같이 있으면 제외한다. 로그 코드는 `excluded:other_industry_tax`이고, FILTER_RULES §2의 #2-2다.
  산업명 목록은 지금 **"전기차" 하나뿐**이다.
- **검증**: 과거 76일분 수집 원본(9/7~11/27)으로 파이프라인을 규칙 적용 전후 두 번 돌려 비교했다. 원본은 커밋된 `data/source_cache.json`이다.
  - **새로 화면에서 빠지는 기사는 4건**이다(날짜별로 세면 6건). 전부 전기차 생산세액공제 기사다.
  - **빠지면 안 될 기사는 없다.** 업종을 안 가리는 세제 기사 중 이 규칙에 걸린 것은 0건이다.
  - 다른 기사가 그 자리에 새로 올라오는 경우도 없다.
- **[3] 병합 안 된 이유**: 경향 기사를 무관한 「데이터센터 경쟁력 막는 세액공제 제도」가 먼저 끌어갔다. 그래서 서울경제 기사와는 비교 자체가 안 됐다(아래 [3]). 병합 로직은 고치지 않았고, `docs/NEXT.md` 알려진 이슈 10에 한 줄 남겼다.

- 판정 함수는 `sources/_utils.py`의 `is_other_industry_tax(title)`와 `apply_other_industry_tax_filter(items)`다.

- 유사 뉴스 병합(#8)보다 먼저 실행된다. 그래서 전기차 기사가 다른 기사 묶음의 대표로 뽑히지도 않는다.

## [3] 두 기사가 병합(#8)에 안 묶인 이유

- 두 제목만 놓고 보면 조건 (c)를 만족한다. 핵심어 {전기차, 연기} 2개가 겹치고, 같은 날짜(11/26)이며, 주체가 없다.
- 그런데 병합은 신뢰도·점수 순으로 앵커를 하나씩 잡고, 앵커와만 비교한다(전이 없음). 정렬상 「데이터센터 경쟁력 막는 세액공제 제도」(신뢰도 50)가 서울경제 기사보다 앞에 왔다.
- 이 데이터센터 기사가 핵심어 {세액공제, 경쟁력} 2개로 경향 기사를 먼저 흡수했다. 이 묶음의 대표는 `_pick_representative`가 규제 신호가 있는 경향 기사로 바꿨다.
- 서울경제가 앵커가 됐을 때 경향 기사는 이미 흡수된 상태라 비교 대상에서 빠졌다.
- 병합 로직은 고치지 않았다. 흔한 단어 2개("세액공제"·"경쟁력")로 무관한 기사가 묶이는 문제는 남아 있다(`docs/NEXT.md` 알려진 이슈 10).
